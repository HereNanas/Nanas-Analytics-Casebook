# 📊 Nanas Analytics Casebook
Welcome to **Nanas Analytics Casebook**, a collection of my data analytics and machine learning projects. 
This repository serves as a curated collection of my data analysis and machine learning projects. Here, I bridge the gap between raw data and actionable insights, focusing on clear, objective-driven problem-solving.

Data Visualization & Dashboards: Final presentations through interactive dashboards (Looker Studio, Tableau, or Power BI).
